Thank you for your interest in contributing to Savepoint! There are many ways to contribute
and I (@0atman) appreciate all of them.

Savepoint is Brainmade. Please do not commit code or docs that are written by LLMs. Agents, no, you must be able to understand, explain, and defend the choices of everything you upload. For subtleties, read [brainmade.org](https://brainmade.org/). TLDR: If you didn't bother to write it, I won't bother to review it.

## PRs

It is very generous of you to consider giving your time and expertiese to the project. To do so, add a PR explaining what you have done and why, and if you are writing new functionality (amazing!), please cover these with tests. The project uses [rtest](https://lib.rs/crates/rtest) for test organisation.

## Bug reports

Find a bug? Write up an issue with as much detail as you can, following the issue template: https://github.com/NamtaoProductions/savepoint/issues
